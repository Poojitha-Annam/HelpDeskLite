# HelpDesk Lite 🎫

**A Web-Based Ticket Management System**

HelpDesk Lite is a web-based application designed to simplify support ticket management. It allows users to raise support tickets, supporters to manage and resolve assigned tickets, and managers to monitor the overall support process.

## ✨ Features

- **User Dashboard:** Create tickets and track ticket status.
- **Supporter Dashboard:** View assigned tickets and update their status.
- **Manager Dashboard:** Manage tickets, assign supporters, and monitor support activities.
- **Role-Based Access:** Separate access for Users, Supporters, and Managers.
- **Ticket Tracking:** Monitor ticket progress and resolution.

## 🛠️ Technologies Used

- Frontend: React.js, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL
- Development Tools: VS Code, Git, GitHub
